## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on travism26/claude-code-adw, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

When you start implementing a Ticket (e.g. `/implement <issue>`), your first write to the tracker is to add the `in-progress` label. See "Claiming a Ticket" in `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: a root `CONTEXT.md` plus `docs/adr/`. See `docs/agents/domain.md`.
