Claude Code playbook

How to get consistently good work out of a coding agent — and how to use one across the rest of the job, not just while writing code.

The idea in one picture

Agent output quality declines as material accumulates in a session — measurably, continuously, and long before any limit is hit. Every practice here follows from that.

Clear between unrelated workFree, immediate, largest quality effect.
Size work to one sessionEverything else is downstream of this.
Write standards downDon't correct in chat. Only habit here that compounds.

Glossary

On evidence. There are no performance percentages anywhere in this playbook, because none could be defended. Chapter 01 sets out what the published research actually establishes, what is a reasonable extrapolation, and what is unsupported — including the fact that degradation is well documented for retrieval and reasoning tasks but thinly evidenced for multi-turn agentic coding specifically. Adopt these practices because the mechanism is sound and they are cheap, not because someone quoted you a number.
